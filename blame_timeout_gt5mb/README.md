# Blame timeout fixtures over 5 MB (HV-145)

Ten JSON files from 6 MB to 40 MB that make remote blame fail on GitHub (GraphQL)
and GitLab, plus two small text files that blame normally.

The earlier `large_blame*` fixtures (2 MB and 5 MB, ~41k long lines) blamed fine.
Blame cost follows the number of lines, so these files use ~14-byte lines, the same
shape as `big-data.json` in `hivelai/test-blame-large-file`, which fails with
`gateway_timeout` at 17.5 MB / 1.25M lines.

| File | Size | Lines |
|---|---|---|
| `data_06mb.json` | 6 MB | ~0.46M |
| `data_08mb.json` | 8 MB | ~0.6M |
| `data_10mb.json` | 10 MB | ~0.75M |
| `data_12mb.json` | 12 MB | ~0.9M |
| `data_15mb.json` | 15 MB | ~1.1M |
| `data_18mb.json` | 18 MB | ~1.35M |
| `data_20mb.json` | 20 MB | ~1.5M |
| `data_25mb.json` | 25 MB | ~1.85M |
| `data_30mb.json` | 30 MB | ~2.2M |
| `data_40mb.json` | 40 MB | ~3M |
| `small_a.txt`, `small_b.txt` | < 1 KB | 50 |

Files are generated by `gen_fixtures.py`.

## Commits (in order)

1. **seed** – adds every file. Additions only, so no blame is needed.
2. **mixed** – rewrites 2000 scattered values in every large file and 10 lines in each small file.
3. **large-only** – rewrites another 2000 scattered values in every large file.
4. **delete** – deletes 500 whole records (2500 lines) from every large file; nothing added.
5. **control** – rewrites lines in the small files only.

## Expected after HV-145

| Commit | Expected |
|---|---|
| seed | classified (new work) |
| mixed | small files classified (new work + rework); each large file has remark `blame unavailable [<category>, <bytes>]: …`, keeps line counts and new work, rework/maintenance/assistance 0; commit completes |
| large-only | every large file marked blame unavailable; commit completes and is not re-queued |
| delete | every large file marked blame unavailable; commit completes |
| control | classified normally, no remark |

If a run hits a rate limit instead, the commit stays retryable and no file is marked.
